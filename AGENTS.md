# Personal Simulation Lab

This monorepo hosts independent simulation projects across topics. Economics is
one area of exploration, not the scope of the repository.

- Keep each simulation in its own descriptive, lowercase, hyphenated top-level
  folder. Place its documentation, research, code, inputs, and artifacts inside
  that folder; create subdirectories only when needed.
- Keep the root README as the lab overview and project index. Each project's
  README owns its purpose, current status, entrypoints, and next steps.
- Read the project's README and relevant design documents before changing it.
  Preserve settled decisions and distinguish proposals from implemented behavior.
- Write documentation and research in English, including project `docs/`
  directories and README files.
- Keep dependencies and run instructions local to each project. Follow its
  existing Python workflow, or use uv when introducing one.
- Keep private inputs, credentials, and restricted source material out of Git.
  Record sources and redistribution terms before adding external data.
