# 애니메이션 스토리보드

실행 결과를 흉내 낸 가짜 그래프는 없어요. 아래는 검증된 모형 출력을 받아
만들 재생기의 화면·동작 설계예요.

## 한 화면

```text
AI·일자리 탐구  [illustrative / 한국 교정 아님]
seed 0042  기간 12/40  [재생/일시정지] [이전] [다음] ──●──  [가정 펼치기]

                 0 AI 미도입       A 도입 격차       B 이동 지연 완화
기업·노동자      ○○ ○○ □□         ○○ ○ □□□         ○○○ ○○ □
선택한 사람 #17  직장→현재상태     직장→훈련중      직장→새 과업
선택한 기업 #3   인원/매출/이윤    인원/매출/이윤   인원/매출/이윤

공통 축: 고용/훈련/미취업 | 실질소득 분포 | 노동/배당 소득 | 매출 HHI
하단: 생산량과 노동생산성, 초기 하위 50% 실질소득의 시간 경로
      [단일 seed 경로] [100개 seed의 쌍별 차이] [회계 잔차]
```

원은 사람, 사각형은 기업이에요. 색과 형태를 같이 사용해 상태를 구별해요.
사람 수가 많으면 점을 집계하되 선택한 ID는 유지해요. 화면마다 초기 배치와
사람 ID를 공유하고 축 범위를 동일하게 고정해요.
소유 분포를 바꾼 비교에는 ‘초기 소유 가정 다름’을 항상 표시해요.

## 60–90초로 읽는 흐름

1. **0–10초: 같은 출발점.** 공통 초기 상태를 보여주고 바뀌는 가정만 강조해요.
   AI 기술 성능과 실제 도입의 막대를 분리해요.
2. **10–30초: 과업이 변함.** 자동화된 과업시간과 남은 인간 과업시간을 보여줘요.
   사람 점을 즉시 삭제하지 않아요. 구인 축소·미충원·배치 변경·이탈이 따로 보여요.
3. **30–55초: 전환 시간.** 선택한 사람의 훈련·대기·재취업 경로와 기업의
   가격·판매·인원·이윤 경로를 동기화해요. 실제 출력에 없는 사건은 연출하지 않아요.
4. **55–75초: 누가 얻었나.** 노동소득과 배당소득을 쌓아 보여주고,
   생산량 증가와 하위집단 소득 변화가 일치하는지 확인해요.
5. **75–90초: 가정 바꾸기.** 수요 반응이나 훈련 지연 한 항목을 바꾸고
   같은 seed로 재실행해요. 다음 화면은 100개 seed 차이 범위로 전환해요.

총 애니메이션 길이는 재생 속도일 뿐 모형 기간의 현실 시간 환산이 아니에요.

## 최소 기능과 합격 기준

- 재생/일시정지, 한 기간 이동, 타임라인 탐색. 정지 중 상태가 바뀌지 않아요.
- seed·엔진 commit·설정 hash 표시, 설정 JSON 저장과 같은 결과 재현.
- 가정 표시는 관측/문헌/가정/산출의 네 분류와 단위·출처·미교정 표시를 포함해요.
- 개인과 기업 ID를 누르면 세 시나리오의 같은 ID를 나란히 추적해요.
- 요약 차트와 원장 합계가 매 기간 일치해야 해요.
- 단일 seed 화면은 설명 예시라고 표시하고 다중 seed 요약을 숨기지 않아요.
- Gini만 보여주지 않고 무소득 비중·하위집단 실질소득·상위 점유율을 함께 확인해요.
- 색만으로 상태를 전달하지 않아요. 키보드 조작과 움직임 줄이기를 지원해요.
- 첫 구현은 Python의 JSON 출력 + 독립 HTML 하나면 충분해요.
  프레임워크·서버·영상 인코더·외부 배포는 필요할 때 추가해요.

후속 단계에서 실제 결과를 재생하는 HTML을 먼저 검증하고, 영상 파일이 필요하면
그때 같은 상태열을 녹화해요. 화면을 그럴듯하게 만들기 위해 결과를 보정하지 않아요.
