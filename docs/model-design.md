# 첫 모형 설계 — 구현 전 검토안

## 질문과 범위

**같은 AI 기술 향상에도, 도입의 격차·새 과업 수요·이동 지연·소유 분포의 조합에
따라 어떤 사람의 실질소득이 증가하거나 감소하나요?**

목표는 조건부 기제 비교예요. 한국의 기업 규모 격차와 노동시장 이동 문제를
동기로 삼지만 한국 경제에 교정된 예측모형은 아니에요.

v0 권장 범위는 한 가상 산업의 부분균형이에요. 200명, 10개 기업, 40기간을
설명용 기본값으로 제안해요. 한 기간은 달이나 연도에 대응하지 않아요.
기업·인구 규모와 기간을 바꿔 결과가 유지되는지도 확인해요.
한국 전체 GDP·실업률·복지 수준으로 해석하지 않아요.

## 최소 상태와 기제

| 단위 | 상태 | 갱신 규칙의 목적 |
|---|---|---|
| 사람 | 고정 ID, 과업 숙련도, 기업/미취업/훈련 상태, 훈련 잔여기간, 현금, 기업 지분 | 소득순위가 바뀌어도 같은 사람의 경로를 추적해요. |
| 기업 | 고정 ID, 기술 도입 상태, 산출·가격·주문, 과업별 구인, 현금, 이윤 | 기업 집중은 판매점유율로 측정해요. 초기 규모가 큰 기업을 반드시 승자로 만들지 않아요. |
| 과업 | 기존 자동화 가능 과업, 보완 과업, 신규 인간 과업 | 자동화 가능한 비율은 해고확률이 아니에요. |
| 외부 부문 | 구매 지출, AI 서비스 수입, 기업에 제공한 자금의 장부 | 부분균형의 외생 수요와 외부 AI 비용을 숨기지 않아요. |
| 정부 | 세수, 이전, 잔액 | 기본값은 세율·이전 0. 재분배는 나중의 별도 실험이에요. |

기업의 AI 도입은 기업별 확률과 비용으로 결정하며 실현 기술은 동일해요.
규모별 도입 확률을 달리하는 실험과 같게 두는 대조를 비교해요.
도입은 비용을 감당할 때만 가능해요. 초기 확산 속도는 외생 가정이며,
이윤이 다시 확산을 강화하는 피드백은 첫 버전에서 제외해요.

산출 1단위에 필요한 인간 과업시간의 후보식은 다음과 같아요.

`h = r × (1 − a × s) + c / (1 + a × b) + n`

- r, c: 초기 과업별 인간 시간, r+c=1.
- a: 도입 상태(0 또는 1), s: 자동화된 기존 과업 비율, b: 보완 과업의 효율 증가.
- n: 새 상품/서비스에 필요한 신규 인간 과업시간. 자동화 효과와 별개예요.
- 총 노동 필요시간은 실제 산출량 × h. 숙련별 구인·충원 후 실제 생산을 제한해요.
- AI 서비스 비용과 도입 비용은 0이 아니어도 돼요. 생산성·이윤 상승을 강제하지 않아요.

기존 과업 대체와 기존 과업 보완은 모두 단위 노동시간을 줄일 수 있어요.
보완이 반드시 고용 증가를 의미하지 않아요. 가격 하락에 따른 주문 확대와
신규 과업 수요가 이를 상쇄하는지가 질문이에요.
신규 과업은 수요와 가격지불 의사를 가진 새 주문에만 붙여요.
기존 주문에 n만 더해 인위적으로 일자리를 만드는 규칙은 쓰지 않아요.

## 구현 전에 고정할 수요·임금 규칙

권장 첫 실험은 외부 고객의 산업 주문과 기업별 가격 경쟁을 사용하는 부분균형이에요.

1. 전기 정보를 사용해 기업이 가격과 목표 생산량을 정해요.
2. 총 목표 주문은 가격지수 변화에 대한 탄력성 ε로 반응해요.
   예: Q*=Q0×(P/P0)^(-ε). 기업 간 배분은 가격과 기존 고객 비중으로 정해요.
   신규 상품 주문은 별도 외생 경로로 주고 지불 비용을 외부 부문에 기록해요.
3. 기업이 필요한 과업 인력을 구해요. 숙련이 부족하면 훈련이 끝난 뒤에만 충원돼요.
   충원 실패 시 판매량을 생산 가능량으로 제한하며 미충족 주문도 기록해요.
4. 실제 판매량으로 매출과 현금이 정산돼요. 임금·서비스 비용·세금·배당도 정산해요.
5. 다음 기의 구인·도입 결정에 이번 결과를 사용해요.

수요 탄력성은 관측치가 아니에요. ε=0, 1, 2 등의 설명용 격자를 비교해요.
가격 규칙·고객 관성도 집중도에 직접 영향을 주므로 반드시 민감도 축으로 남겨요.
외부 고객 지출의 증가를 국내 가계 구매력에서 나온 것처럼 설명하지 않아요.

첫 임금 규칙은 숙련별 동일한 기준임금으로 시작하고, 두 번째 규칙에서만
구인난·구직난에 반응하는 조정 임금을 비교하는 안을 권해요.
기준임금을 고정한 모형으로 임금 상승 여부를 발견했다고 주장할 수 없어요.
협상력·최저임금·연공급을 전부 한꺼번에 추가하지 않아요.

회사별 잉여 이윤은 실제 비용을 차감한 잔액이에요. 소유 가중치 합계는 기업마다 1.
배당은 양의 이윤과 현금 범위에서만 지급해요. 손실을 지워서 배당하지 않아요.
현금 부족은 명시적 자금조달 또는 생산 축소로 처리하며 숨은 무제한 신용은 금지해요.
도산·진입은 v0 제외이므로 고정 기업집합의 집중도라는 한계가 있어요.

## 비교 설계

동일 seed에서 초기 사람·기업·소유·과업 상태를 복제해요.
무작위 수는 (seed, 기간, 개체 ID, 사건 종류)별로 고정하여 분기 때문에
시나리오 간 난수 순서가 어긋나지 않도록 해요.

| 비교 | 바꾸는 조절 가정 | 고정할 것 |
|---|---|---|
| 0 대조 | AI 도입 없음 | 초기 상태, 외부 주문 충격, 기준 임금 |
| A 확산 | 소기업 도입 지연: 없음 / 큼 | AI 성능, 신규 수요, 이동 지연, 소유 |
| B 재배치 | 훈련 지연: 0 / 2 / 8기간, 신규 과업 주문: 없음 / 있음 | 도입 경로, 기술, 초기 소유 |
| C 배분 | 소유 집중 / 분산, 같은 총 지분 | 생산·고용 경로를 먼저 고정한 회계 비교 |

0/A/B/C는 중립 이름이에요. 결과를 본 뒤 winner-takes-all로 이름 붙이는
자동 분류기는 만들지 않아요. 소유 실험은 초기조건을 일부러 바꾸므로
동일 초기조건 비교와 화면에서 구별해요. 배당 소유만 바꾸고 구매력 피드백을
제외했다면 생산이 같게 나오는 것은 모형 구조이지 실증 발견이 아니에요.

처음에는 한 축씩 비교하고 이후 작은 요인설계로 상호작용을 살펴봐요.
유리한 가정을 한 묶음으로 넣은 ‘낙관’과 불리한 묶음의 ‘비관’만 비교하지 않아요.

## 결과와 불평등 정의

- 고용률: 전체 고정 인구 중 고용된 사람. 미취업과 훈련 상태를 별도 표시해요.
  이것을 실제 한국의 실업률이라고 부르지 않아요.
- 채용·이직·고용 이탈의 흐름, 총 생산량, 실제 노동시간당 생산량.
- 노동소득, 배당소득, 세후 이전 포함 소득을 분리해요.
- 동일 소비 바스켓 가격지수로 실질화한 개인 소득의 중앙값·하위 50% 평균·상위 10% 점유율.
- 전원 소득 Gini와 취업자 임금 Gini를 따로 보고, 기업 매출 HHI=Σ점유율²를 함께 봐요.
- 무소득자를 빼지 않아요. 평균 소득 0이면 Gini는 정의 불가로 표시해요.
  음수 개인소득을 허용하는 확장에서는 표준 Gini 해석을 다시 정의해야 해요.
- 초기 소득 계층별 변화와 매기 재분류한 분위별 변화를 구별해요.
  ‘K자’는 초기 집단 경로를 먼저 봐야 해요.

가계 구성·주택자산·연금·해외 자본·인구감소·비정규직 구분은 제외돼요.
개인 배당소득 분포를 한국 가구 자산 불평등이라고 부르지 않아요.
총 생산 증가, 하위집단 실질소득 증가, 고용 안정이 서로 엇갈릴 수 있어요.

## 검증 계약 — 엔진 구현 후 반드시 실행할 것

지금은 검사 설계이며 **아직 실행·통과한 시뮬레이션 검사는 없어요**.

| 검사 | 기대 관계 또는 실패 조건 |
|---|---|
| 인구·시간 보존 | 고용+미취업+훈련=고정 인구. 중복 소속 없음. 개인별 사용시간≤보유시간. |
| 생산 가능성 | 판매≤생산. 각 과업에 필요한 시간이 공급시간 이하. 생산성과 노동시간의 단위 일치. |
| 기업 손익 | 이윤=판매수입−임금−AI/도입 등 비용. 비용을 노동소득이나 생산량에 이중 가산하지 않음. |
| 현금 | 기말 기업현금=기초현금+수입+명시적 조달−비용−세금−배당. 가계·정부·외부 부문도 동일. |
| 거래 상대방 | 임금 지급 합=노동소득 수령 합, 배당 지급 합=지분별 수령 합, AI 비용=외부 수입. |
| 재정 | 정부잔액 변화=세수−이전−명시적 지출. 이전을 생산 증가에 더하지 않음. |
| 전체 장부 | 모든 부문 포함 순현금 변화=명시적 외부 통화 공급. 미기록 잔차 금지. |
| 부가가치 | 산업 매출−구입 중간투입=임금+세전 잉여(단순화 정의). 매출을 GDP로 표시하지 않음. |
| 재현 | 같은 설정·seed·엔진 버전은 동일 상태/출력 hash. 시나리오 표시 순서를 바꿔도 결과 동일. |
| 대조 | 기술·비용·수요·훈련 변화 0이면 AI 라벨만으로 결과가 바뀌지 않음. |
| 극한 | 전원 동질·대칭 조건에서 설명 없는 우위가 생기면 실패. 동률 배정의 seed 효과는 별도 확인. |
| 작은 수기 예제 | 2기업·4명·1기간의 생산·임금·이윤·세금·배당을 손계산한 장부와 대조. |
| 오류 입력 | 음수 비용·확률 범위 이탈·지분 합≠1·NaN은 실행 전에 거부. |
| 분포 계산 | 전원 동소득 Gini=0; [0,0,0,4]의 비보정 Gini=0.75; 점유율 합=1. |

금액은 부동소수점 허용오차를 규모에 비례해 명시하거나 최소 화폐 단위 정수로 계산해요.
장부 검증 실패 시 애니메이션 생성도 중단해요.

### 한 seed로 결론을 내리지 않는 기준

초기 탐색 seed 0–99를 미리 고정하고 같은 seed끼리 시나리오 차이를 계산해요.
쌍별 차이의 중앙값·10–90% 범위·부호가 유지되는 비율을 보여줘요.
이는 무작위 실행 변동이지 현실 예측의 신뢰구간이 아니에요.

수요 탄력성, 임금 규칙, 소유 분포, 과업 결합 방식(고정비율/대체 가능),
기업 수·초기 불평등을 바꿔 결론의 방향이 뒤집히는 영역을 찾어요.
무작위 불확실성과 모형 구조 불확실성을 따로 보여줘요.
같은 사람의 수십 기간을 독립 표본처럼 세지 않아요.

## 다음 구현을 여는 두 선택

1. **범위**: 위의 부분균형 과업·기업 모형부터 시작할지, 가계 소비까지 연결한
   폐쇄경제를 먼저 만들지 선택해야 해요. 전자를 권해요. 후자는 구매력 피드백을
   다루지만 저축·신용·수요 회계 가정이 훨씬 늘어요.
2. **첫 화면의 중심**: 도입 격차와 재취업 경로를 먼저 볼지, 자본소유·배분을
   먼저 볼지 선택해야 해요. 전자를 권하고 소유는 별도 실험으로 붙이는 안이에요.

이 선택과 수요·임금 규칙 검토 전에는 본 시뮬레이터를 구현하지 않아요.
