# Continuous empirical film

Build with `npm run build`; serve with `npm run dev`; open `/film.html`.
The source entries are `/` and `/cinema.html`. The current engine is
`web/empirical-model.mjs`; legacy provider/individual checks do not apply.

## Exercise and judge

1. Confirm one continuous scene with both schematic work settings visible. The
   controls name practice proprietors and salaried physicians; no P1–P16 picker or
   viewpoint tabs remain. Default artifact text is English and sparse. Patient
   movement must be obvious in successive frames, including within one model year.
2. Verify default 16-second progression, brief endpoint hold, and repeat. At 2x,
   check the eight-second horizon and endpoint stop with Loop disabled. Pause must
   freeze both year and actor positions. Scrubbing pauses and resets the action
   phase reproducibly. Loop/Play are buttons with aria-pressed, not input checkboxes.
3. Click either group to open results without changing year or assumptions. Change
   a preset/parameter at 2036 and compare visible indices, per-role earnings,
   retention and clinical work with the current model frame. Retention is a share
   of original modeled positions; it is not a national headcount or an inference
   from the 8/16 illustrative actor slots.
4. Check the chart's sensitivity bands and numerical ranges against the exported
   finite design. The ranges are extrema, not confidence intervals. Workforce
   context must not be described as role weights; observed earnings must say 2020
   and the 2026 index must be identified as an assumed relative baseline.
5. Download scenario/results using the UI. Inspect the actual saved JSON, then
   rerun its parameters and structure through the engine and sensitivity helper.
   Require exact annual-frame and sensitivity equality. A completed click or a
   browser download-event timeout alone does not establish the file outcome.
6. Inspect desktop and 390x844: both buildings and their signs, moving people,
   readouts and playback controls fit. Open both drawers; check readable source
   disclosures, sticky close controls and no horizontal overflow. In reduced
   motion, startup is paused and incidental motion suppressed; explicit playback
   can advance years. Reset viewport and media overrides afterward.
7. Check the final portable build and browser error/warning logs. Save a useful
   screenshot and concise observations in artifacts/verification.md. Leave the
   delivered scene running at normal speed unless the user requests pause.

Patient flow is illustrative rather than a count or validated queue. Judge its
visible response to both increased and decreased modeled care. Source checks and
successful clicks alone cannot establish motion quality. Keep aesthetic acceptance
open for user feedback. Distinguish HTTP portable verification from direct file use.
